## 5. 波次成长与属性计算

沿用上一轮方案：第 1 波为最小值，设置的最终波为最大值，中间线性增长。不要把“12 波”写死。

```text
progress = clamp((Current_Wave - 1) / max(Total_Wave_Count - 1, 1), 0, 1)
心之钢固定部分 = round(1 + 24 * progress)
光盾/血肉固定部分 = round(50 + 200 * progress)
十字军每次固定减伤（依既定成长口径的建议） = round(15 + 65 * progress)
```

准备阶段展示预览时应标明使用当前已完成波还是即将进攻波；实际收益在对应触发时按权威波次计算，避免显示与结算错一波。

以 12 波为例：第 1/4/8/12 波固定值分别为心之钢 1/8/16/25，光盾与血肉 50/105/177/250。

- [x] 百分比伤害/治疗强化只记录本模式提供的额外加成，不依赖原始英雄数据表，不覆盖既有英雄技能临时倍率。
- [x] **前置修正：分清百分比与生命点数。** 已拆成 `feskaHealthPercent(p)`（`setMaxHealth` 用百分比）与 `feskaMaxHealth(p)`（实际生命点数＝`Base_Max_Health` × 加成% ＋ 心之钢 ＋ 护甲强化）。`Base_Max_Health` 在初始化与换英雄时读 `getMaxHealth()`，不维护英雄表。
